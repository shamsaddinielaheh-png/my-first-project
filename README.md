# Code Breaker (Mastermind)
### 🎯 Goal
Guess the computer's secret 4-digit code within 10 attempts.

### 📜 Rules
- The secret code contains 4 different digits.
- Each digit is between 1 and 6.
- Repeated digits are not allowed.
- You have a maximum of 10 attempts.
- After each guess, the game provides feedback:
  - **Correct Position:** A digit is correct and in the right position.
  - **Wrong Position:** A digit is correct but in the wrong position.
- Invalid guesses do not count as attempts.

### 💡 Hints
- Pay attention to the feedback after each guess.
- Use the correct-position count to identify digits in their exact places.
- Use the wrong-position count to find digits that belong to the secret code but need to be moved.
- Think carefully and use each attempt wisely!

**Good luck and have fun!**
